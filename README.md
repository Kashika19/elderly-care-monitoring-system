# Elderly Care Monitoring System

> **Status:** Existing university work being prepared for publication

A systems case study exploring how monitoring technology could support elderly-care workflows while considering usability, privacy, safety, and responsible design.

## Portfolio focus

- Stakeholders and user needs
- Functional and non-functional requirements
- System architecture and data flows
- Monitoring and alert workflows
- Accessibility, privacy, and ethical considerations
- Testing and evaluation

